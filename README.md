# SQL-Projects

A collection of SQL projects and queries covering data extraction, transformation, and analysis across various real-world datasets.

## Overview

This repository contains SQL scripts written for data analysis tasks — from exploratory queries to complex multi-table joins and aggregations used to power dashboards and reports.

## Skills Demonstrated

- **Data Querying** — SELECT statements, filtering with WHERE, sorting with ORDER BY
- **Aggregations** — GROUP BY, HAVING, COUNT, SUM, AVG, MIN, MAX
- **Joins** — INNER JOIN, LEFT JOIN, RIGHT JOIN, and multi-table joins
- **Subqueries & CTEs** — Nested queries and Common Table Expressions for readable logic
- **Window Functions** — ROW_NUMBER, RANK, PARTITION BY for advanced analytics
- **Data Cleaning** — Handling NULLs, deduplication, and type casting
- **Database Design** — Understanding schemas, primary keys, and relationships
